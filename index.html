RAD SQUADTACTICS

Turn-based squad skirmishes. Spend action points to move, shoot and flank — but hold what you don't spend, because leftover AP is what shoots back on your opponent's turn.

An original tactics game built in tribute to the 2012 mobile squad-tactics games of that era. All characters, art, maps and code here are original — no assets or code from any commercial game are used.
